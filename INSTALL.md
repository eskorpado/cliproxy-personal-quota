# Установка «Моих квот» агентом

Подключи плагин к существующему CLIProxyAPI пользователя в **OpenCode Desktop**. Инструкция одинакова для Windows, macOS и Linux. Используй инструменты конфигурации, редактирования файлов и чтения HTTP, доступные в текущей сессии. Терминал, установка Node.js и сборка не требуются.

### 1. Найди подключение

Начни с провайдера выбранной модели. В метаданных OpenCode (`provider.list`, если доступен через интеграцию) или в настройках `providers` найди его **ID** и **`settings.baseURL`**. Нужен включённый провайдер с пакетом `@opencode/ai/providers/openai-compatible`. Из HTTPS URL возьми только `origin`: схему, хост и порт. Не используй адрес с логином, паролем, query или fragment. Не извлекай ключи и не выводи целиком конфиг или ответ API.

Убедись, что это CLIProxyAPI: прочитай `/.well-known/cpa-quota-policy.json` на найденном origin **без авторизации**. Требуются `schemaVersion: 1`, массив `pools` и тот же origin без перенаправления. Если несколько подключений подходят и выбор неясен, спроси только имя провайдера. Если каталог не найден, сообщи об этом; не подбирай посторонний сервер.

### 2. Добавь плагин в глобальные настройки

Найди активный пользовательский `opencode.json` или `opencode.jsonc` через сведения о конфигурации OpenCode (пути документов `config.get`, если доступны) или файловым инструментом. Учитывай переопределённый каталог конфигурации; обычное расположение — `.config/opencode` в домашней папке пользователя, в том числе `.config\opencode` в профиле Windows. Не записывай origin в репозиторий проекта.

В массиве `plugins` добавь **одну** запись, заменив `my-cpa` и `https://cpa.example.org` найденными значениями. Если этот плагин уже установлен локально или из предыдущего релиза, замени его запись. Сохрани остальные настройки и комментарии JSONC. Если пользовательского файла ещё нет, можно создать его по этому образцу:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [{
    "package": "github:eskorpado/cliproxy-personal-quota#v0.1.4",
    "options": { "providerID": "my-cpa", "origin": "https://cpa.example.org" }
  }]
}
```

OpenCode загрузит готовые серверную и GUI-части с GitHub. Ключ плагин возьмёт из действующего подключения; в `options` его указывать не нужно.

### 3. Проверь результат

В **Настройки → Расширения → Плагины** на встроенном сервере Desktop проверь, что `cliproxy-personal-quota` активен. Если у агента есть интеграция с API OpenCode, он может проверить это сам через `plugin.list`: статус `active`, функции `server` и `gui`. Для проверки чтения квоты доступен локальный RPC `cliproxy-personal-quota.snapshot` с входом `{"revalidate":true}`. Если у агента нет доступа к API или экрану, сообщи, что именно удалось проверить, и попроси пользователя открыть **`/quotas`** в чате или **«Мои квоты»** в меню **+** боковой панели.

Свежий снимок без ошибки и с пустым списком означает, что плагин подключён, но ключу не назначены доступные квоты. Ошибка `provider` указывает на несовпадение ID или origin, `key` и `unauthorized` — на проблему активного подключения, `catalog-*` — на проблему каталога. Не подменяй рабочий режим демонстрационным. Для удаления достаточно убрать запись плагина из `plugins`.
